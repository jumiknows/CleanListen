# Security and Data Handling

CleanListen processes documents and labeled text. Keep private, licensed, or sensitive material out of public issues and commits unless redistribution is allowed.

## Do not commit

- private research papers
- participant data
- credentials or API keys
- documents containing personal information
- generated artifacts that contain source text you do not have permission to redistribute

Use public or synthetic examples when reproducing bugs.

## Reporting

If a problem could expose private documents, credentials, or stored data, report it privately to the repository owner rather than attaching the material to a public issue.

## Model and benchmark integrity

A model-quality issue is not automatically a security issue, but benchmark changes should remain reproducible. Do not remove provenance, split details, or limitations to make results appear stronger.
